# dramisinfo-web

Site vitrine de **DramisInfo** — systèmes sur mesure pour les PME du Québec.

Astro 5 · Tailwind 3 · Netlify. Français (défaut) et anglais.

```bash
npm install
npm run dev      # http://localhost:4321
npm run build
```

Le contenu rédactionnel vit dans `src/i18n/ui.ts`.
Les couleurs et les fontes vivent dans `design-tokens.mjs`.

Voir [CLAUDE.md](CLAUDE.md) pour le positionnement, les règles de contenu et l'identité visuelle.
